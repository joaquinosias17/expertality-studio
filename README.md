# Expertality Studio

Marketing site and demo app for Expertality Studio: brand teams set the rules once, every franchise location gets a ready week of on-brand posts and reels to approve.

- `/` landing page
- `/app` brand calendar (demo), `/app/create` idea to post, `/app/week` store owner view
- `/api/lead` walkthrough requests, logged to Vercel runtime logs until a CRM is connected

Mesa Coffee Co. is a fictional sample brand. Photos are hotlinked from Unsplash.

```
npm install
npm run dev
```
